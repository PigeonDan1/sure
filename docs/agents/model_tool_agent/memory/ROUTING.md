# Memory Routing

This file controls optional memory selection for the model tool-agent. The goal
is to keep default context small while still making hard cases discoverable.

## Always Read

- `memory/COMMON.md`
- `task_playbooks/ROUTING.md`
- `playbooks/env_ROUTING.md`

## Read Only On Trigger

| Trigger | Read | Why |
|---------|------|-----|
| Validation or build fails with a known error class | `playbooks/failure_taxonomy.md` | Classify the failure before retrying. |
| Retry decision is needed | `policies/retry_and_escalation.md` | Decide retryability and stopping conditions. |
| Patch to upstream/runtime/config is proposed | `policies/patch_recording.md` | Ensure patch reason and scope are recorded. |
| Host capability, GPU, Docker, registry, network, or TMPDIR risk is relevant | `playbooks/preflight_checklist.md` | Run targeted preflight checks. |
| Input is generated by XForge bridge | `playbooks/xforge_sure_bridge.md` | Follow scaffold and artifact expectations. |
| Error resembles a known bad case | `memory/bad_cases/README.md` first, then the matching case file if present | Avoid loading unrelated bad cases. |

## Bad Case Routing

Bad cases are not default context. A bad case requires both:

1. an observed symptom or error string; and
2. a matching entry in `memory/bad_cases/README.md`.

If no bad-case entry matches, use `playbooks/failure_taxonomy.md` for
classification instead of reading all bad cases.

## Audit Record

When optional memory is read, record:

- observed trigger;
- files read;
- files intentionally skipped;
- decision made from that memory.

Example:

```json
{
  "context_selection": {
    "memory_files_read": [
      "docs/agents/model_tool_agent/playbooks/failure_taxonomy.md"
    ],
    "trigger": "VALIDATE_LOAD failed with missing_weights",
    "memory_files_skipped": [
      "docs/agents/model_tool_agent/memory/bad_cases/README.md"
    ],
    "reason": "generic failure classification was sufficient"
  }
}
```
